# Meus sites favoritos

Atividade de Programação Web I, desenvolvida com base no conteúdo de HTML da Agenda 12.

## Autora

Aparecida Nogueira N. Petak

## Objetivo

Criar uma página com cinco sites favoritos. Cada site apresenta seu nome acima de uma imagem e um link de acesso abaixo dela.

## Sites apresentados

- YouTube
- Wikipédia
- GitHub
- Khan Academy
- Spotify

## Recursos utilizados

- Estrutura básica de HTML5.
- Título da aba com `<title>`.
- Títulos com `<h1>` e `<h2>`.
- Imagens com `<img>` e os atributos `src` e `alt`.
- Quebras de linha com `<br>`.
- Links com `<a>` e os atributos `href` e `target`.
- Comentários no código HTML.

A página não utiliza CSS.

## Arquivos do projeto

- `index.html`: código da página.
- `youtube.png`: imagem do YouTube.
- `wikipedia.png`: imagem da Wikipédia.
- `github.png`: imagem do GitHub.
- `khan-academy.png`: imagem da Khan Academy.
- `spotify.png`: imagem do Spotify.
- `capturas/`: pasta destinada às capturas do código comentado e da página em execução.
- `README.md`: descrição do projeto.

As imagens são ilustrações com os nomes dos sites, não logotipos oficiais.

## Como visualizar

Baixe os arquivos e abra `index.html` em um navegador.

As cinco imagens devem permanecer na mesma pasta do arquivo HTML para serem exibidas corretamente.
